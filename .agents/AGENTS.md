# Project Rules

- Whenever you start a new chat, resume an existing conversation, or switch to another topic in this project, you MUST read the `BITACORA.md` file located in the root directory of this workspace to get the latest context and project state (in case changes were made in another conversation).
- After every change you make to the code, you MUST update `BITACORA.md` with the new progress and do a `git push` to synchronize everything with the repository.
